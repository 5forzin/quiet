Quiet's first stable Windows release.

- Install for your Windows account with the included runtime. Git and Node.js are not required.
- Updates use published stable releases and verify the installer SHA-256 before running. Drafts, prereleases and `main` commits are excluded.
- A compact dark extension lets you select the sites to share with your local agent.
- The mini control and live viewer use the same charcoal surfaces and Windows controls.

Download **Quiet-1.0.0-windows-x64.exe**. The installer is not code-signed; Windows may display an unknown-publisher warning.

Requires Windows 10 2004 or later, x64, and Microsoft Edge. Load the prepared extension from `%LOCALAPPDATA%\Quiet\extension` through `edge://extensions` once. Reload it after extension updates.

Sessions and preferences live in `%LOCALAPPDATA%\Quiet` and survive updates and uninstall. Quiet provides MCP tools for an existing agent client; it does not include a model. Only cookies are transferred, and some sites may require another sign-in.
